# Macos Contextual Search

## 2026-09-06 — macOS Contextual Search tool -- architecture decisions

**Decisions:** v1 query surface is a pure terminal CLI (e.g. `csearch "..."`), not a Finder Sync extension -- avoids Xcode/code-signing/manual-extension-approval overhead for an MVP. Nothing is ever hard-deleted: dupes/unneeded files move to a dated quarantine folder with a manifest; permanent removal is a manual step Dex takes afterward. Embeddings go behind a pluggable `EmbeddingBackend` interface: Apple MLX as the default/primary (native to Apple Silicon, no PyTorch), sentence-transformers as a second swappable backend for models MLX doesn't have ports of yet -- not run simultaneously on every file/query by default, since that doubles compute for no ranking benefit unless scores get fused (that fusion is a possible v2, not a v1 requirement). OCR: Apple Vision framework primary (native, no install), Tesseract (Homebrew) as fallback only when Vision returns empty/low-confidence text. Execution happens via a local Claude Code session on Dex's Mac through Terminal -- this cloud session writes the code but cannot run/install anything on his machine.
