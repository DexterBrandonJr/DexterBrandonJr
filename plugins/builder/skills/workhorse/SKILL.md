# Workhorse (coordination copy)

Dex builds systems one way, and it works. The full doctrine — with the
personal constraints it is shaped around, the templates, the domain
playbooks and the build record — is private, in `DexterBrandonJr/workhorse`.
This public copy carries only what is safe to keep on a profile repo: the
shape, the rhythm, and how to reach the rest.

## 1. Reach the full doctrine

Attach `DexterBrandonJr/workhorse` to the session and read `DOCTRINE.md`
§1–§4 before proposing anything. Its `.claude/skills/workhorse/` has the
scaffold script and the complete procedure. If the repo cannot be attached,
proceed with this file and say so.

## 2. The shape of every system

Eight parts. A project missing one is not done.

| Part | What it is |
|---|---|
| **The record** | One row per thing that happened, with the context it happened in. Never an illustrative row. |
| **The gate** | The rules that decide what may happen — pure, protected, breakable only by a failing test, re-checked at the moment of acting. |
| **The loop** | Scheduled work that runs whether or not anyone is at a screen: sweep → decide → act → score → review. |
| **The surfaces** | The instrument (phone), the console (desk), the manual. One database, one visual system. Every feature that ships has its place on a surface in the same change. |
| **The scorer** | Every prediction timestamped before its outcome and scored after. |
| **The review** | Right / wrong / could not have known / will do differently, from the record, written where the next run reads it. Proposals only. |
| **The counterfactual** | The paths not taken are scored too. |
| **Staged autonomy** | Stage 1 a human approves everything; Stage 2 the system adjusts within what was approved; Stage 3 it acts alone where the record says it has earned it. A halt from anywhere lowers; only a human raises. |

## 3. The rhythm

Research the discipline → the vision document → the working agreement →
the blueprint filled in its own structure → build in ordered increments,
each a merged pull request with the suite green and its surface view in
the same change → one deposit per session, named → memory as a committed
file → QA/QC like an adversary → the failure protocol (one line at the
top, fixed in the same response, the class recorded, move on).

## 4. The confidence contract

**Proven** (happened, observed) · **Tested** (asserted in code) ·
**Expected** (reasoning). Never blurred; never hedge what is Proven;
predictions on the record before the outcome, then scored.

## 5. Reading the request

Directional instructions are vectors with floors — pick a number when one
is needed and say it was picked. Analogies name a discipline to import,
not an identity to imitate. Scope words are inclusive. Safety belongs in
the code, not the conversation; a real present risk is said once, at the
top. Every reply ends with the plain-language summary, short lines, the
payload at the bottom; acronyms spelled out on first use.

## 6. Where projects live

Each project gets its own private repo with its own memory. This public
repo is the coordination point and carries a pointer per project and
nothing sensitive.
